## Pasting on Linux

Handy can now paste into regular apps and terminals with the same key. With the **Clipboard (Shift+Insert)** paste method, Handy puts your transcript on the clipboard and on the primary selection (the text you last highlighted, which most terminals paste), presses Shift+Insert, then puts both back.

This is now the default for new installs. If you use **Direct**, we recommend switching: Direct presses a key for each character, so it depends on your keyboard layout and can drop capital letters or accented characters, or type the wrong ones. You can change it in **Advanced → Paste Method**.

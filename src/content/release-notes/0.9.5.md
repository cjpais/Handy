## Linux: Phantom Recording Fix

If Handy on Linux sometimes started recording on its own, or cut off a real
dictation mid-sentence (typically about 2 minutes in), that was a signal
conflict: Handy listened for `SIGUSR1` as a remote-control trigger, but
WebKitGTK — the webview engine embedded in Handy — uses the same signal
internally for JavaScript garbage collection. Every GC cycle looked like a
hotkey press ([#1660](https://github.com/cjpais/Handy/issues/1660)).

Handy no longer listens for `SIGUSR1` on Linux.

**If you bound `pkill -USR1 -n handy` to a hotkey, replace it with:**

```bash
handy --toggle-post-process
```

`SIGUSR2` (plain transcription toggle) is unchanged and keeps working.

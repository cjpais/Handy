# Tolkovo — продуктовый план

Этот файл — источник правды о том, что мы строим. Читать перед любой задачей.

## Что это

Tolkovo — форк [Handy](https://github.com/cjpais/Handy) (MIT, CJ Pais).
Бесплатная, офлайн, приватная голосовая печать для macOS, сделанная для
русскоязычных людей. Нажал хоткей — сказал — текст появился там, где курсор.

Позиционирование: «Говори с нейросетями голосом — бесплатно и по-русски».
Главный сценарий: люди весь день пишут Claude, ChatGPT, Cursor — длинные
промты быстрее наговорить, чем напечатать.

## Принципы (не нарушать)

1. **Бесплатно навсегда.** Никаких подписок, триалов, платных функций, лицензионных ключей.
2. **Приватно.** Аудио и текст не покидают компьютер. Никакой телеметрии и аналитики —
   даже opt-in. Единственное сетевое обращение — загрузка модели.
3. **Тихо.** Никаких напоминаний о донатах внутри приложения. Донат — только пункт меню по клику.
4. **Минимализм.** Пользователь видит только пилюлю. Окно настроек открывается при первом
   запуске и потом только по его желанию.
5. **По-русски из коробки.** Ноль настроек для русскоязычного человека.
6. **Лёгкий апстрим.** Меняем только то, что нужно. Внутренние имена Handy в Rust
   (крейты, модули, `handy_app_lib`) НЕ переименовываем — чтобы забирать обновления
   из `upstream` с минимумом конфликтов.

## Решения, которые уже приняты

- **Имя:** Tolkovo / «Толково». Проверено: не занято (Talkey, Tolki — заняты).
- **Bundle ID:** `com.kozliq.tolkovo`
- **Модель по умолчанию:** GigaAM v3 E2E-RNN-T (русская, с пунктуацией). Whisper Large v3 Turbo —
  для тех, кому нужны другие языки.
- **Хоткей по умолчанию:** ⌥ Space (как в Handy).
- **Дистрибуция:** GitHub Releases + DMG + GitHub Pages. Не App Store.
- **Автообновление Handy:** отключено (ключи и эндпоинты принадлежат оригиналу).

## Дизайн

- **Пилюля** — вертикальная, плавающая поверх всех окон и рабочих столов.
  - В покое: прозрачное жидкое стекло (Liquid Glass).
  - Запись: стекло наполняется красным (плавный переход, не резкая смена цвета).
  - Перетаскивается мышкой в любое место экрана, позиция запоминается.
- **Живой текст:** во время записи рядом с пилюлей растёт стеклянный пузырь, в котором
  появляются распознанные слова (перераспознавание буфера каждые ~0.5 с). В поле ввода
  вставляется только финальный текст после отпускания клавиши. Слова в чужое окно
  «вживую» не печатаем — правки гипотез ломают ввод в браузерах и мессенджерах.
- **Стекло:** `tauri-plugin-liquid-glass` (NSGlassEffectView на macOS 26+,
  фолбэк NSVisualEffectView на 14–25). Требует `macOSPrivateApi: true` и прозрачных окон.
- **Иконка:** `branding/icon-1024.png` — стеклянная пилюля с микрофоном, наполненная красным.
- **Без Dock:** приложение живёт в строке меню, автозапуск при входе, старт скрытым.

## Продвижение (кратко)

Telegram-канал с дневником разработки с первого дня → статья на Хабре в день релиза
(история + сравнение моделей на русской речи с англицизмами) → рилсы
(сплитскрин «печатаю vs говорю», «перестал печатать промты») → r/macapps →
Homebrew и awesome-списки после 50 звёзд. «Итоги месяца» — встроенный виральный механизм.

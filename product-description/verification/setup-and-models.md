# Verification: setup and models

How to run this file: the three setup documents (LAUNCH, PERM, CHOOSE) want a fresh state: quit Handy, move `~/Library/Application Support/com.pais.handy` aside, and, where an item says "no cached models", also move `~/.cache/huggingface/hub` aside; reset the system permissions with `tccutil reset All com.pais.handy` when an item says "fresh TCC" (Accessibility is removed by hand in System Settings › Privacy & Security › Accessibility). Several setup items need a catalog model already in the Hugging Face cache; download one in a normal run first, then move only the application-support directory aside. The three models documents (DL, SWITCH, MPAGE) want onboarding completed with one or two models downloaded: Parakeet Unified EN 0.6B active, Whisper Medium as the second (**batch-model**, slow enough to watch loading), every setting at its default, the settings window visible. Device values are defined in [README.md](README.md); the ones used here are mac, mic, shell, network-off, secure-input, debug, log, batch-model, and no-model. Items that use the mirror block Hugging Face with a line `127.0.0.1 huggingface.co` in `/etc/hosts` (remove it afterwards); these say **shell**. Keep a terminal open on `~/.cache/huggingface/hub` and `~/Library/Application Support/com.pais.handy/models` to see files arrive and go.

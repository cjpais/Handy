# Verification: settings

How to run this file: start from a clean state with onboarding completed and one model downloaded and active (Parakeet Unified EN 0.6B, which is English-only, so the per-model card on General is absent until an item says **batch-model**, meaning Whisper Medium, which has both a Language row and a Translate to English toggle). Every setting at its default: push to talk on, Audio Feedback off, Experimental Features off, debug mode off, Overlay Live / Bottom, History Limit 5, theme System, language English. Keep the settings window visible and on the page under test unless an item says otherwise; most claims here are about what the window shows, so a hidden window blocks them. TextEdit with a new plain-text document is the paste target for the items that dictate. Device column values are defined in [README.md](README.md); the ones this file uses are **mac**, **mic**, **usb-mic**, **bt-mic**, **batch-model**, **no-model**, **llm**, **bad-llm**, **network-off**, **secure-input**, **debug**, **log**, and **shell**. Items that edit `settings_store.json` do so with Handy quit and restore the file afterwards.

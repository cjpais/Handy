# Verification: cross-cutting

How to run this file: start from a clean state with onboarding completed, defaults everywhere, and two models downloaded — Parakeet Unified EN 0.6B (active unless an item says otherwise) and Whisper Medium (**batch-model**; every LANG item that dictates in another language or needs a picker uses it). The **secure-input** condition is Terminal.app with Terminal › Secure Keyboard Entry checked and Terminal frontmost; the condition clears when Terminal is sent to the back or the menu item is unchecked, so for items that click inside Handy's window under Secure Input, confirm with `ioreg -l -w 0 | grep -i SecureInput` (a `kCGSSessionSecureInputPID` line) that it is still held after bringing Handy forward, and record the item as blocked if it is not. For DISK items keep a Finder window open on `~/Library/Application Support/com.pais.handy` (About › App Data Directory › Open) with the Date Modified column showing, and a Console or `tail -f ~/Library/Logs/com.pais.handy/handy.log` beside it. PLAT rows are macOS-verifiable only where they describe the macOS column; every Windows and Linux claim is listed under "Not checkable by hand (needs Windows/Linux)" and must not be marked pass or fail from a Mac. TextEdit with a new plain-text document is the paste target; keep the settings window visible unless told otherwise. Device column values are defined in [README.md](README.md).
